# Calculadora de IMC

Programa en Python que calcula el Índice de Masa Corporal (IMC) a partir de la edad, el peso (kg) y la estatura (m) del usuario.

## Validaciones

- No permite campos vacíos.
- Si se ingresan letras en lugar de números, muestra un error y vuelve a pedir el dato.
- No acepta valores menores o iguales a 0.

## Cómo ejecutarlo

1. Instala Python 3.
2. Clona o descarga este repositorio.
3. Abre una terminal en la carpeta del proyecto.
4. Ejecuta: `python imc.py`
5. Escribe tu edad, peso y estatura cuando el programa lo pida.

## Reflexiones personales

Al principio todo me pareció difícil: las variables, los operadores, las cadenas y sobre todo las validaciones. Pero con constancia y paciencia le fui agarrando a todo, probando el código una y otra vez hasta que funcionó.

Me llevo que equivocarse es parte del proceso: cada error en la terminal me enseñó algo. Me gustaría seguir aprendiendo Python para hacer programas más completos.
